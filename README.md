# 📊 SkyblockTracker

> Десктопное приложение на Java для отслеживания игровой статистики, аналитики рынка и мониторинга предметов в Minecraft Hypixel Skyblock.

![JavaFX](https://img.shields.io/badge/JavaFX-17%2B-blue?style=for-the-badge&logo=java)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey?style=for-the-badge)

---

## 🌟 Основные возможности

* 📈 **Мониторинг рынка (Bazaar/NPC/Forge):** Отслеживание цен на предметы в реальном времени, анализ прибыли и поиск выгодных сделок для флиппинга.
* 💾 **Кэширование данных:** Оптимизированные запросы к API с сохранением истории цен для построения наглядных графиков и трендов.
* 🖥 **Удобный GUI:** Понятный и быстрый десктопный интерфейс без лишних задержек.

---

## 🛠 Технологический стек

* **Language:** Java 17
* **GUI Framework:** JavaFX
* **API Integration:** SkyApi (JSON)
* **Build Tool:** Maven
* **Libraries:** Gson(для парсинга JSON), HttpClient
